# Scoop bucket for Refryt

[Refryt](https://github.com/gridoe/refryt) is a lightweight YouTube Music client. This bucket
installs its Windows build (x64 or ARM64) with [Scoop](https://scoop.sh):

```powershell
scoop bucket add gridoe https://github.com/gridoe/scoop-bucket
scoop install gridoe/refryt
```

`scoop update refryt` moves to a new release. The manifest follows the project's GitHub releases.
